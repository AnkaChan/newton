# LearnedClothOptimizer (LCO) — One-Page Summary

*(Method & training philosophy level; for reproduction-grade details see `reports/lco-architecture-study.md` with file:line references.)*

**What it is.** LCO is a *learned optimizer* for implicit cloth simulation — not a learned simulator. Each frame poses the classical incremental-potential problem: minimize E(x) = inertia + StVK membrane + dihedral bending + gravity + body-collision penalty + Coulomb friction over cloth vertex positions x. Instead of Newton or L-BFGS, a graph transformer is applied **30 times per frame** ("Cells"): each Cell reads the current iterate and its (detached) energy gradient, and emits a bounded position update. Physics, collision detection, and hard feasibility projection remain fully classical; only the descent rule is learned. Classical L-BFGS / Newton-CG baselines run in the same harness with the same objective for fair comparison.

**Per-Cell loop.** candidate → ∇E via autograd (then detached: gradients are observations, not training paths) → network → update = exp(log s)·d → planar Divide-And-Truncate (DAT) safety projection → commit. A recurrent state (last gradient, last update, log step size) persists across Cells and frames.

**Representation.** Tokens are cloth vertices (the body enters only as per-vertex closest-point features); edges are mesh topology. 40 input channels in three groups — geometry/motion (centered current coords, velocity, iterate-minus-inertial), contact (8 channels each vs. current and next-frame body material points), and optimizer history (RMS-normalized gradient, previous gradient rescaled by the current RMS, previous update, plus separate log-magnitude channels). The organizing principle is **scale separation**: direction distributions are normalized per-sample; absolute magnitudes travel in dedicated log channels. Material parameters condition every block via FiLM. Absolute rest coordinates are disabled (dataset-pose poison); features are translation-invariant but *not* rotation-equivariant.

**Network.** Four pre-LN graph-transformer blocks (width 96, 8 heads, ≈0.66M params). Attention is true softmax attention over sparse topological relations, implemented on flat edge lists with scatter-based segment softmax; 8-dim edge features add per-head score biases. Receptive field comes from an **exact-k-hop relation schedule** [1, 2, 4, 1] (dilated attention); heads can split across multiple hop relations at zero parameter cost. An optional bi-stride topological V-cycle exists as an alternative multiscale mode.

**Output.** Two zero-initialized heads: a per-vertex direction squashed radially into the unit ball, and a **per-garment scalar step size** — a recurrent log-scale trust-region controller with asymmetric grow/shrink rates, hard-clamped to [10 µm, 5 mm] (per-vertex step sizes caused artificial strain). Untrained network = exact no-op. Safety is structural, not behavioral: bounded direction, clamped step, DAT projection, health resets.

**Training.** Fully self-supervised by physics: L = asinh(E_after / max(|E_before|, 1)) + ReLU(ΔE/scale) — no trajectory ground truth, no MSE. The asinh keeps heavy-tailed energies from dominating gradients; the one-sided hinge restores linear pressure against energy ascent where asinh saturates. Training is **on-policy**: two persistent simulation environments generate states with the current policy (no noise injection needed), with gradients truncated to a single Cell (one-step BPTT). DAT enters the training graph via a bit-exact straight-through operator (truncation-weighted surrogate Jacobian, 5% minimum gradient).

**Status & limits.** Trained on HOOD garments / VTO body motions (60 Hz); multilayer contact branches fine-tuned separately with a frozen backbone. World-frame directional features mean rotation generalization relies on data coverage — the main open surface for an equivariant retrofit.
