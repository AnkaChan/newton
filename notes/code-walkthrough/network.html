01 Transformer and network

One network call proposes a new set of local deformation axes for every cell of every object in the batch. The learned part of the solver lives in three modules under experiments/learned_intrinsic_solver/: network.py holds the attention block IntrinsicTransformerLayer and the full predictor IntrinsicSolverNetwork; network_geometry.py builds the fixed 27-slot neighborhood of a cuboid grid and the 24-value descriptor of every directed edge; features.py is the single source of truth for the per-cell state vector and the six conditioning channels. The network runs once per solver iteration: MixedHexSolverStep.forward first lets assemble_inputs compute frames, local axes, state, edge and conditioning tensors from the current candidate corners, then calls the network and hands its targets to fusion. Training constructs the module in run_training with the campaign configuration: cell counts 10 × 10 × 40 (N = 4,000 cells), hidden width 128, edge width 64, four heads, one radius-one block (hops = [1]), query chunks of 128 cells and a step bound of 0.05. Built on the CPU, that configuration has 323,214 trainable parameters; the neighbor index and mask tensors are registered buffers and are not counted.

The network never sees world coordinates. Every matrix it reads or writes is expressed in the receiving cell's own rotation frame R, which the caller extracts from the current deformation and detaches. The network's output is a target for the local axes A = RᵀF, not a vertex position; a separate assembly step reconciles the 4,000 per-cell targets into one shared shape.

The 70-value node input

Each cell is one token. Its input is the current local axes (9 values) followed by 61 state values, concatenated inside the network to a 70-wide vector. The current axes are the cell-center deformation gradient F, a 3 × 3 matrix whose columns are the three transformed material directions, rotated into the cell frame:

F_ij = sum over the 8 corners k of (x_k - x_0)_i * G_kj      G = signs / (4 h), units 1/m
A    = Rᵀ F                                                 dimensionless, identity at rest
node_input = [ A flattened row-major (9) | state (61) ]     70 values per cell

Row-major flattening means entry (i, j) of the matrix lands at position 3i + j; the correction head uses the same layout in reverse. F is differentiable in the corner positions (center_deformation), and to_local is a plain Rᵀ @ M with no detach, so whether A carries a gradient depends on what the caller passes in. The state vector is packed by pack_state_features in exactly this order:

The five matrix blocks are 45 values, the boundary metadata 14, the trailing scalars 2: STATE_FEATURE_DIM = 61. The checkpoint schema version for this layout is 3; older 38- and 86-value layouts are rejected by the physics step rather than reshaped.

Key implementation points:

  • All five matrix blocks share one shape [B, C, 3, 3], dtype and device; the boundary flags may be [C, 14] shared across the batch (the physics step registers them as a buffer of that shape) or [B, C, 14]. The result is [B, C, 61] in the dtype of the matrix blocks.
  • Both history blocks are overwritten with zeros wherever history_valid is false, regardless of the tensors supplied, so a missing history can never be mistaken for a measured zero. The flag itself is the last column.
  • rms_normalize computes sqrt(mean over cells and components of value²) per object, clamps it to at least RMS_FLOOR = 1e-12, divides and clips to ±CLIP = ±10. The clip acts on local-frame components, which is why the caller rotates into R before normalizing. When a second field reuses another field's rms, that rms is passed in and floored again.
  • Nothing in features.py detaches. In the assembly that feeds the network, the frame R, the objective gradient G and the history are detached; A, the inertial axis offset and the physical axis change remain differentiable functions of the candidate corners, while Y and the physical-start positions are held fixed.

Six conditioning channels

Material and timestep information does not enter the node vector. It arrives as six dimensionless per-object scalars that the network turns into a 128-channel embedding and applies through FiLM inside the block. The channels, in order, are:

c1 = log1p(λ / 1e5 Pa)              first Lamé parameter
c2 = log1p(μ / 1e5 Pa)              shear modulus
c3 = log(ρ / 1000 kg/m³)            density
c4 = log(h / 0.025 m)               rest cell size
c5 = log(dt / (1/60 s)) = log(60 dt)  physical timestep
c6 = log1p(η / (μ dt))              viscosity relative to μ dt; η itself is unchanged

conditioning_channels returns [B, 6]. The physics step expands it to [B, N, 6] before the call; the network accepts either shape and broadcasts [B, 6] over cells itself. In the campaign configuration h = 0.025 m gives c4 = 0 exactly and dt = 1/300 s gives c5 = log(0.2), about -1.61, for every object. The materials are not value-checked here, and bad values are only partly visible: ρ ≤ 0 makes c3 nonfinite and μ = 0 makes c6 nonfinite (0/0 when η = 0, η/0 otherwise), but λ = 0 and η = 0 are valid inputs that give c1 = 0 and c6 = 0, and negative values of small magnitude pass through as finite channels. The range checks live upstream: both register_context and HexImplicitEulerLoss require μ > 0, ρ > 0, λ ≥ 0 and η ≥ 0 before materials reach this function. Inside the network, condition_encoder maps 6 → 128 → SiLU → 128; the result is the conditioning argument of every block, whose FiLM layer therefore has 128 input channels.

27 neighbor slots per cell

Attention is restricted to a fixed local neighborhood: each cell attends to itself and to the 26 cells that share a face, an edge or a corner with it. build_grid_neighborhood enumerates these slots once for the whole grid; the same table is used for every object in the batch because all objects share the canonical cuboid topology.

cell id(x, y, z) = x · ny · nz + y · nz + z            z varies fastest
slot 0           = offset (0, 0, 0)                     self
slots 1 to 26    = every (dx, dy, dz) with max(|dx|, |dy|, |dz|) = 1, in lexicographic order
valid(cell, slot) = neighbor coordinates inside [0, nx) × [0, ny) × [0, nz)
invalid slot     → index 0, mask false
  • Returns neighbor_indices (int64) and neighbor_mask (bool), both [N, S] with S = 27 for hop 1. For the 10 × 10 × 40 grid that is [4000, 27]; 92,512 of the 108,000 slots are valid, and a cell has between 8 valid slots (a corner cell: itself plus seven neighbors) and 27.
  • Invalid slots hold index 0 so that gathers stay in range; the mask, not the index, says whether a slot exists. Slot 0 is always valid, so no cell has an empty attention row.
  • The network registers the two tensors as buffers named neighbor_indices_1 and neighbor_mask_1, so they move with .to(device) and are saved in the state dict. Larger hops (2 and 4 give 99 and 387 slots) are supported by the builder but the campaign uses only hop 1.

The 24-value directed edge descriptor

Cells in different places have different frames, so a neighbor's geometry is only comparable after it is transported into the receiving cell's frame. build_edge_features does this for every (receiver i, slot j) pair. With R the detached frames, c the current cell centers (the mean of the eight current corners), X the rest centers and h the rest cell size:

rest_offset       = (X_j - X_i) / h                 3 values; integer grid offsets (dx, dy, dz) up to float32 rounding
current_offset    = R_iᵀ (c_j - c_i) / h            3 values; where the neighbor is now, seen from i
relative_frame    = R_iᵀ R_j                        9 values, row-major; converts j-frame vectors into i-frame
transported_axes  = R_iᵀ R_j A_j = R_iᵀ F_j         9 values, row-major; the neighbor's deformation in i's frame

edge(i, j)  = [ rest_offset | current_offset | relative_frame | transported_axes ]   24 dimensionless values
masked slot = 24 zeros
self slot   = [ 0, 0, 0 | 0, 0, 0 | identity | A_i ]
  • Output shape [B, N, S, 24], in the input dtype without promotion; float32 stays float32. All four geometry inputs must share one floating dtype and device.
  • frames.detach() is applied inside the function, so no gradient reaches the frame extraction through edges. current_centers and local_axes are not detached; their autograd links are left to the caller.
  • If the whole object is rotated by a rigid Q, every R and F picks up the same left factor and the products R_iᵀ R_j, R_iᵀ F_j and R_iᵀ (c_j - c_i) are unchanged: the descriptor is invariant to global rotation and translation. The 128 hidden channels the network builds from it are learned features, not world-space vectors.
  • Invalid slot indices are first replaced by 0 so the gathers are safe, and the finished features are zeroed at masked slots. The network masks them once more before its edge encoder as a guard against poisoned padding.

Three encoders and one block

IntrinsicSolverNetwork.__init__ creates the encoders, one IntrinsicTransformerLayer per configured hop, an output LayerNorm and the two heads. All three encoders are two linear layers with a SiLU between them:

node_encoder:      70 → 128 → SiLU → 128       one token per cell
edge_encoder:      24 →  64 → SiLU →  64       once per hop, shared by every block
condition_encoder:  6 → 128 → SiLU → 128       feeds each block's FiLM
  • state_feature_dim is 61 and 9 + state_feature_dim = 70 is the node encoder's input width. The physics step refuses a network whose state, conditioning or edge widths differ from features.py.
  • The block is constructed with conditioning_dim = hidden_dim = 128: it receives the encoded condition, not the raw six channels.
  • Both heads and their biases are zero-initialized, so a freshly built network returns the current axes unchanged as its target and a step of half the bound.

In forward, the condition is encoded once, the axes and state are concatenated and encoded into tokens, and the raw edges of each hop are masked and encoded once. The blocks then run in order, each with its own hop's edges and topology:

Inside the transformer block

The block is a pre-LayerNorm transformer layer with three additions: FiLM modulation of both normalized branches, a learned per-head score bias from the edge, and a learned per-edge addition to the value. Written out, with x the incoming tokens, e the encoded edges and c the encoded condition:

(γ1, β1, γ2, β2) = split(film(c), 4)                     each [B, N, 128]; film is zero-initialized

n      = LayerNorm(x) · (1 + γ1) + β1
q, k, v = split(W_qkv n)                                  each [B, N, 4 heads, 32]
s_ij   = (q_i · k_j) / √32 + edge_bias(e_ij)              one score per head; -∞ at masked slots
w_ij   = softmax over the 27 slots of s_ij                masked weights set to exactly 0
m_i    = Σ_j w_ij (v_j + edge_val(e_ij))                  per head, concatenated back to 128
x'     = x + W_out m                                      attention residual

n'     = LayerNorm(x') · (1 + γ2) + β2
y      = x' + W2 SiLU(W1 n')                              W1: 128 → 512, W2: 512 → 128

The modules, in construction order: two LayerNorms, the fused query-key-value projection 128 → 384, edge_bias: 64 → 4 (one bias per head), edge_val: 64 → 128 (one 32-vector per head), the output projection, the feed-forward pair with multiplier 4, and film: 128 → 512 whose weight and bias start at zero so the modulation begins as the identity.

FiLM. The condition is broadcast to [B, N, 128] if it arrived per object, passed through film and split into four 128-channel pieces: scale and shift for the attention branch, scale and shift for the feed-forward branch. The scale is applied as 1 + γ, so zero weights mean no change. A layer built with conditioning_dim = 0 has no FiLM and rejects a condition tensor.

Masked attention in query chunks. Queries are processed 128 cells at a time. For each chunk the code gathers the keys and values of the 27 slots, zeroes the edge features at invalid slots before the two edge projections, adds the per-head edge bias to the scaled dot product, fills invalid slots with -∞ and takes the softmax over slots. A row with no valid slot cannot occur with the canonical topology, but it is still made safe by replacing its scores with zeros before the softmax so no NaN reaches the backward pass. The message adds edge_val(e_ij) to each neighbor's value before weighting, so the edge shapes both how much a neighbor is heard and what it says.

  • Shapes per chunk of size n: scores and weights [B, n, 27, 4], edge_values [B, n, 27, 4, 32], message [B, n, 4, 32] reshaped to [B, n, 128]. With N = 4,000 there are 32 chunks (31 of 128 cells and one of 32).
  • Chunking only bounds the temporary gathers of one chunk. Autograd still stores every chunk's activations, so it does not reduce training memory, and every query still sees all 27 slots.
  • When return_attention is set, the weights are returned as [B, N, 4, 27] with invalid entries exactly zero; ordinary training does not request them.

Bounded correction, per-cell step, target axes

After the block, one LayerNorm feeds two linear heads that read the same normalized token. The correction head produces nine raw values per cell and squashes them so that the joint nine-value norm is below one; the step head produces one scalar per cell and passes it through a sigmoid scaled by the configured bound:

z      = LayerNorm(y)                                    [B, N, 128]
raw    = W_c z + b_c                                     [B, N, 9]
corr   = raw / sqrt(1 + ‖raw‖²)  reshaped to 3 × 3       ‖corr‖ < 1, direction of raw preserved
step   = max_step_size · sigmoid(W_s z + b_s)            [B, N], each value in (0, max_step_size)
target = A + step · corr                                 [B, N, 3, 3], same frame as A
  • The step is per cell: step_size has shape [B, N] and is broadcast over the 3 × 3 matrix with step_size[..., None, None]. Every cell scales its own correction; there is no object-level scalar.
  • With the campaign bound 0.05 the step lies in (0, 0.05); at zero initialization sigmoid(0) = 0.5 gives 0.025 for every cell, and the zero correction makes target = A. A zero output is representable, but fusion does not necessarily return the same shape for it.
  • The nine-value bound limits the size of the local axis change per query. It says nothing by itself about energy descent or about whether the assembled shape stays valid; those are checked downstream.
  • The return value is the IntrinsicSolverOutput tuple (local_target_axes, axis_correction, step_size). The physics step then forms world_increment = R (target - A) = step · R corr and passes it to fusion (call site); the network itself never touches vertex positions.

Where gradients enter and leave the network. During training, the loss reaches the network through target: fusion and the energy are differentiated back to step · corr, then through both heads, the output LayerNorm, the block, the three encoders and their inputs. Of the inputs, the frame R, the gradient blocks, the log rms, the history and the flags are constants of the query. A, the two deformation-difference blocks and the edge offsets and axes are functions of the candidate corners, but the trainer detaches the candidate at the query boundary, so no gradient crosses into earlier iterations or timesteps.
