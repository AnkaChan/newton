01 Transformer and solver network

One network call proposes a new local shape for every cell. The network receives the current cell axes, the physical state, and nearby cell geometry. It predicts three target axes in the same cell frame. A separate fusion stage turns all those targets into shared vertex positions. IntrinsicSolverNetwork and its attention block, IntrinsicTransformerLayer, are ordinary PyTorch nn.Module classes. The current configuration uses one block, selected by hops=[1], with 128 hidden channels and four attention heads. Constructing this configuration on the CPU gives 326,414 trainable parameters; topology indices and masks are buffers, excluded from that count. Network class · Training construction

What one cell receives

The input builder first gathers a cell’s eight corners, computes its deformation matrix, and extracts a local rotation frame. It treats that frame as fixed during differentiation. The current axes are the deformation matrix expressed in that frame. They are dimensionless: identity means rest shape, while their lengths and angles carry stretch and shear. The network sees their nine entries, followed by 86 additional state values. Input builder

The damping metric is FᵀF, which describes lengths and angles without world rotation. Its change compares the candidate with the start of this physical timestep, held fixed across that timestep’s solver iterations. At each Gauss point the packed order is xx, yy, zz, √2·xy, √2·xz, √2·yz. The square-root factors preserve the matrix’s squared norm when packed into six values. Metric difference · Packing

Six separate scalar inputs condition the block: log1p(λ / 100000 Pa), log1p(μ / 100000 Pa), log(ρ / 1000 kg/m³), log(h / 0.025 m), log(dt / (1/60 s)), and log1p(η / (μ·dt)). Here λ and μ are Lamé elastic coefficients, ρ is density, h is rest cell size, and η is the absolute damping coefficient. The last ratio normalizes a network input; the physical damping coefficient remains η. Each object’s six values are broadcast to its cells. Exact scalar construction

The canonical rest shape is a cube of side h. Its size enters through h, the normalization of geometric vectors, and the rest-grid offsets. This input layout contains no current energy-gradient channel, previous optimizer-gradient channel, or recurrent hidden state. There is no axis_gradient argument in the current network interface. The physical-start damping data is its explicit temporal input. Forward arguments · Complete feature assembly

How neighbors enter the receiving cell’s frame

Each cell has 27 fixed slots: itself plus the 26 cells sharing a face, edge, or corner. Boundary slots outside the cuboid have a false mask. The network therefore uses the same layer for interior and boundary cells. A slot is a neighbor location, not a feature dimension. Neighborhood construction

Each directed edge has 24 raw values: rest-center offset divided by h (3), current-center offset in the receiver’s frame divided by h (3), the neighbor-to-receiver frame rotation (9), and the neighbor’s axes transported into the receiver’s frame (9). For receiver i and neighbor j, RᵢᵀRⱼ converts a vector from j’s frame into i’s; multiplying it by j’s local axes expresses those axes in i’s coordinates. Rest offsets use the common material reference coordinates. This conversion makes neighbors comparable despite their different frames. Rotating the entire physical configuration rotates the frames with it and leaves these local inputs unchanged. The 128 hidden channels are learned features, not world-space XYZ vectors. Frame transport and feature order

The edge encoder maps 24 → 64 → 64 using a SiLU activation between its linear layers. Its weights are shared across edges. The node encoder similarly maps 95 → 128 → 128, and the scalar encoder maps 6 → 128 → 128. The three encoders

One transformer block, step by step

LayerNorm first normalizes each cell’s 128 hidden channels. FiLM then lets material and timestep information adjust those channels: multiply by a learned scale and add a learned offset. A linear map turns the 128-channel scalar embedding into four 128-channel vectors: scale and offset for attention, and scale and offset for the feed-forward branch. The scale is applied as 1 + scale; zero-initialized FiLM weights therefore begin as an identity adjustment. Block modules · FiLM application

A linear projection produces query, key, and value vectors. Each of four heads receives 32 channels. For each neighbor, a head scores the receiver’s query against that neighbor’s key, divided by √32. edge_bias maps the encoded edge to four additional scores—one per head. Softmax converts these scores into weights over the valid neighbor slots.

edge_val has a different job: it maps the edge to 128 values, split across the four heads, and adds them to the neighbor’s value vector. Each head sums these geometry-adjusted values using its attention weights. Thus the edge influences both how much attention a neighbor receives and what information that neighbor sends. Both projections are learned; no fixed distance-based attention preference is inserted.

Missing neighbors are masked before projection and receive exactly zero attention. The four head outputs are concatenated, projected, and added to the incoming token: the attention residual. A second LayerNorm and FiLM adjustment feed an MLP with widths 128 → 512 → 128 and SiLU activation. Its output is added through another residual. Queries are processed in chunks of 128 cells to reduce temporary gathers; every query still sees all 27 slots. Chunking does not shrink its neighborhood or remove stored training activations. How hidden tokens become target axes

After the block, LayerNorm feeds a nine-value correction head for each cell. Dividing its output by sqrt(1 + sum(raw²)) preserves its direction and bounds the combined nine-value norm below one. The controller averages hidden tokens over all cells, predicts one scalar per object, and applies 0.05 × sigmoid(scalar). That shared step multiplies every cell’s bounded correction. Adding the result to the current axes produces the target axes in the same frozen local frame.

This is nine correction values per cell plus one shared object-level step, rather than ten independent outputs per cell. The correction may vary from cell to cell, including its magnitude. The network returns targets, corrections, and the shared step; it does not directly return vertex positions or a rigid transform. Fusion and geometric acceptance follow outside the network.
