This walkthrough follows train_mixed.run_training() and MixedHexSolverStep, using the saved campaign configuration. One physical timestep advances simulation time. Within it, several solver iterations improve a candidate shape while the timestep's physical reference stays fixed. One network query performs one such iteration.

The graph nodes are cells. The actual simulated shape is stored as shared corner positions. A local proposal from one cell cannot independently move a corner that is also used by neighboring cells; assembly reconciles their proposals.

Scope of this snapshot. The implemented energy uses logarithmic Neo-Hookean elasticity and rejects nonpositive determinants at its Gauss points. The frame and initializer paths impose additional orientation checks. The saved configuration enables geometry backtracking. Those restrictions are described where they occur in the code.

A small vocabulary for the rest of the page
Cell / hexahedron
A volume element with eight corner references. Rest cells are cubes; current corners can form a warped shape.
Deformation gradient F
A 3 × 3 matrix describing how a small displacement in rest coordinates changes in the current shape. Its columns are three transformed material axes.
Frame R
Three orthonormal coordinate directions used to express a cell's vectors locally.
Local axes A
The deformation axes expressed in R: A = RᵀF. The axes retain length and angle changes.
Gauss point
A sample location inside an element used to approximate its energy integral. There are eight per cell here.
Gradient / backward pass
A gradient measures how a scalar changes when its inputs change. Backpropagation combines these derivatives to update the network weights.
Detach / no_grad
A deliberate boundary that prevents differentiation through an earlier computation or state.
Factorization / adjoint
A factorization prepares a fixed matrix for repeated linear solves. The adjoint is the transposed solve used to propagate a gradient through assembly.
