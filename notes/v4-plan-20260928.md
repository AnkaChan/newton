## Representation (core)

| Item | Decision |
|---|---|
| Per-cell targets | 21 = 7 vectors x 3: the three axes (columns of the centre deformation gradient F) plus four warping vectors (bilinear xi^b xi^c for the three pairs and trilinear xi^1 xi^2 xi^3). All seven rotate as world vectors under the frozen frame R_c, so the local representation is R_c^T [a_1 a_2 a_3 w_12 w_13 w_23 w_123]. `target_modes = 7`; `target_modes = 3` keeps today's affine-only behaviour for ablations and legacy tests. |
| Fusion | Per-Gauss-point target increments derived from the 21 values, so the per-cell fit is exact and only shared-corner agreement remains; unknowns (corners), system size, sparsity and factor caching unchanged; only the assembly changes. Energy path (F at 8 Gauss points from corners) unchanged. |
| State blocks | The five nine-value blocks become 21-value blocks in the same 7-vector basis (inertial offset, physical change, current gradient projected onto the 7 modes through the fusion adjoint, previous gradient, previous update). Node input = 21 + 5 x 21 + 14 flags + 2 scalars + 17 contact = 159. |
| Width | hidden 192, 6 heads (head dim 32), FFN x4, edge hidden 96; contact encoder unchanged (64). |
| Schema | feature_schema_version 6. |

## Data and training

| Item | Decision |
|---|---|
| Regime | Fixed-state epochs (2048 states), growth timetable as run 3, budget cap raised to 2048 (H = 128 -> K <= 16, H <= 64 -> K <= 32) so deep iterations stay in the mix. |
| Contact | kappa range [0.5, 10] (floor raised from 0.1). |
| Scale | Gravity magnitude sampled per state, log-uniform in [2, 40] m/s^2 along -y, so the dimensionless groups Lambda and Gamma are covered at fixed h and dt (equivalent to varying cell size and time step for the normalised network). Per-context gravity in the physics step. |
| Selection | Best checkpoint chosen on the full-horizon check (16 states, K = 8, H = 128, every epoch): mean final free-corner residual with survival required; final energy and deepest penetration recorded alongside. Cheap 64 x 8 validation kept for the curves. |
| Optimizer | AdamW 1e-6, clip 1.0, cosine 1e-4 -> 2.5e-5 over max_epochs 48, no early stopping. |
| Translation for unpinned bodies | Centroid Newton step with the rigid target recomputed from the current contact force (see notes/fusion-integrator-derivation.md); implemented AFTER the v4 launch as a follow-up because every v4 scene is pinned. |
